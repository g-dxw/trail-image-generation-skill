# 案例一：江津柏林之巅

## 输入概况

- 类型：KMZ 徒步环线
- 距离：约 9.02 km
- 累计爬升：约 808 m
- 时长：约 6 小时 26 分
- 核心主题：山脊、绳索、竹梯、寺庙、赤色岩壁

## 核对后的全局点位

`柏林镇出发点 → 风里雨里打卡处 → 漏孔弯 → 寨门 → 绳索攀爬段 → 华一峰 → 玉皇庙 → 竹梯险段 → 观音庙 → 柏林之巅 → 废弃村落 → 赤色岩壁 → 山神庙 → 柏林镇`

## 提示词片段

> 竖版 3:4 中文徒步旅行地图，水彩与墨线，严格沿参考截图保留不规则闭环路线；下方左侧柏林镇出发，路线沿右侧上升，穿过上方山脊后沿左侧下降返回；绿色“上山”、金色“山脊线”、橙红色“下山”，显示 13 个全局编号点位。不要复制卫星底图、地图文字、图钉或手机界面。

## 复盘
