## 跨夜节点

每个跨夜节点都要同时写入总览图和相邻两张日详图：

```text
节点名称：
全局点位编号：
轨迹进度：
第 N 天状态：结束 / 住宿 / 露营 / 撤离
第 N+1 天状态：起点 / 续行
事实来源：轨迹 / 照片 / 用户确认
```

## 生图一致性检查

- [ ] 总览图与每日详图使用同一条路线几何
- [ ] 每日详图只突出当天路线，其余路线降为 inset
- [ ] 全局点位编号没有重排或重置
- [ ] 颜色、方向箭头、跨夜符号一致
- [ ] 每日统计没有误写成全程统计
