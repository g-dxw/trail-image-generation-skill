# 轨迹几何合同

本文件定义路线生图时不可被画风、文案或构图覆盖的几何约束。第 7 阶段必须与 `prompt-rules.md` 一起读取。

## 1. 轨迹精度模式

- `exact`：精确轨迹/严格遵循轨迹，默认模式。完整保留已确认 PNG 中的路线轮廓、拓扑、方向、起终点关系、分段边界、inset 和编号锚点。
- `similar`：结构相似，仅在用户明确要求时使用。允许局部简化，但保留整体轮廓、主要转折、方向、起终点关系和点位顺序。
- `free`：氛围自由，仅在用户明确要求时使用。只保留路线类型和大致方向。

画风、平台、用途和“直接生成完整效果图”均不改变精度模式。未记录明确降级授权时一律使用 `exact`。

## 2. 优先级

- P0：轨迹 PNG、路线拓扑、行进方向、起终点、分段边界、inset、全局编号和点位锚点。
- P1：标题、正文、数据卡、字体、地标插画、照片框、背景、城市天际线和装饰。

发生空间冲突时，只能移动、缩小或减少 P1 内容，不得移动、遮挡或重画 P0 内容。

## 3. 几何锁定区

每张包含路线的提示词都必须包含且原样执行以下区块：

```text
[GEOMETRY_LOCK_BEGIN]
优先级：P0，覆盖构图、美术、文字和装饰要求。
轨迹参考PNG：<绝对路径；实际作为 route_geometry 参考图传入>
路线SVG：<绝对路径；校验资产>
布局JSON：<绝对路径；校验资产>
轨迹精度：<exact/similar/free；默认 exact>
路线类型：<开放/闭合/折返>
方向：<已确认方向>
起终点：<已确认关系>
锚点：<全局编号、名称、track_progress、anchor>
分段/inset：<范围和表现>
禁止重画、简化、镜像、旋转、擅自闭合、移动锚点、改变编号或改变分段边界。
冲突时移动或缩小文字、地标、信息卡和装饰，始终保持轨迹完整可读。
[GEOMETRY_LOCK_END]
```

执行阶段必须从已确认的提示词文件读取该区块，不得凭记忆重写、压缩、翻译或摘要。

## 4. 参考图片角色

每个实际传入的参考图必须标注唯一角色：

- `route_geometry`：轨迹 PNG；严格模式必需，且优先级最高。
- `real_photo`：需保留原始照片内容的素材。
- `ai_scene`：仅提取已确认特征的地标参考。
- `style_reference`：只约束媒介、色彩和质感，不影响路线几何。

SVG 和布局 JSON 是校验资产，不假设生图模型能直接解析。不得用风格参考图覆盖轨迹参考图的几何权重。

## 5. 执行清单

每次正式调用前使用 `build_generation_manifest.py` 生成清单，再用 `validate_generation_manifest.py` 校验。清单至少记录：

- task id、精度模式、分段起止范围；
- 提示词文件及 SHA-256；
- 轨迹 PNG、SVG、布局 JSON 及 SHA-256；
- 路线是否闭合、点位数量、编号、名称、进度和锚点；
- 所有参考图的绝对路径和角色。

校验失败必须停止，不得调用生图工具。

## 6. 分段参考图

总览图使用完整路线。路段详图必须基于同一个布局 JSON 和 `simplified_progress`，将当前路段高亮，其余路线低对比显示；不得重新手绘一条近似路线。点位沿用全局编号。

## 7. 生成后验收

模型返回成功不等于路线验收通过。至少核对：

- 整体轮廓和路线类型；
- 方向、起终点和闭合关系；
- 分段范围和 inset；
- 点位数量、顺序、编号和锚点位置；
- 路线是否被文字、地标或装饰遮挡。

不合格输出不得标记为正式版本。允许一次针对性重试：保留同一几何锁定区，只调整发生冲突的 P1 构图。仅强化提示词可以显著降低漂移，但不能承诺像素级一致。
